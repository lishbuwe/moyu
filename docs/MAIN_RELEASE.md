# 主网页 0.6.16.2

发布至 lishbuwe/moyu 的 main，来源为 YL2C/moyu 的 0.6.16-personal.2（0faf55e16ed09a7035eebe5ba96d11174cce7c01）。功能和玩法要求保持一致，应用标题恢复为“墨游”。

## 原版数据兼容

- 数据库继续使用 `moyu`，结构版本仍为2；不新建个人版数据库，不迁移、不覆盖既有故事、角色、连接、密钥或默认规则。
- 当前故事标记继续使用 `moyu.curStory`；缓存继续使用 `moyu-v` 前缀，仅刷新网页资源，不删除IndexedDB或localStorage。
- 已保存的番外模板保留编辑内容并补充新版要求；API选择和人物选择从新建番外表单设置。
- YL2C个人网页仍使用自己独立的存档位置，本次发布不修改YL2C分支。

## 新功能

四个动态番外玩法、论坛/聊天/报告/节目/同人排版、独立番外API、记录主人及报告人选择、恋综多选随行人、静态弹幕、紧凑聊天、完整报告；以及番外后台接回、拆卡、多选输入、规则分组批量管理与折叠、主角状态更新及折叠、台词主题配色与手动检查更新。所有故事数据仍存在使用者本机。

`docs/PERSONALIZATION.md`记录个人版历史约定；其中个人数据库和发布分支说明不适用于本主网页发布，部署以本文件为准。
